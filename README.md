~ Sebelum run Main aplikasi klinik, lakukan :
1. Download Laragon lalu install. Download "adminer-costum.zip" dan "haha.sql" (repo ini)
2. Di path "laragon\www" paste folder adminer-costum yang sudah di ekstrak (kalau belum ada folder "www", buat folder sendiri dengan nama yang sama).
3. Buka laragon lalu klik tombol "start all".
4. Klik tombol "Database", lalu copy Hostname / IP.
5. Buka browser lalu paste IP yang di copy, lalu tambahkan "/adminer-costum/" setelah IP. Contoh : "127.0.0.1/adminer-costum/"
6. Masuk dengan username "root" dan password null (kosongin)
7. Import file haha.sql yang sudah di dwonload (di repo ini)
8. Buka folder AplikasiKlinik yang sudah di download dan ekstrak (pakai NetBeans atau vscode)
9. Run file Main.java (untuk username dan password bisa liat di database haha; pastikan udah mengikuti semua langkah diatas)
